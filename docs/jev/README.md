# JEV workspace

JEV means **Just Enough Validation** for this project. The goal is to test the riskiest business and messaging assumptions before building a separate market funnel or making irreversible positioning changes.

## Run one cycle

1. Choose one hypothesis.
2. Interview or observe the smallest useful set of qualified prospects.
3. Record answers without storing unnecessary personal data.
4. Tag the evidence using [02-question-bank.md](02-question-bank.md).
5. Add the result to [04-review-log.md](04-review-log.md).
6. Decide: **continue**, **revise**, **scale**, or **defer**.
7. Update [01-decision-record.md](01-decision-record.md) only when the decision changes.

## Evidence rules

- A booking is evidence of action, not evidence of qualified demand.
- Language is a baseline proxy, not proof of geography.
- An opinion is evidence of perception, not proof of willingness to pay.
- A paid Clarity Sprint is the strongest current commercial signal.
- Do not use tiny samples to claim a statistically winning message.
- Separate what the code proves from what the business still assumes.

## Current cycle
