# Nebula Ideas business and JEV workspace

This folder records the Mexico-first business, messaging, and website-learning plan for Nebula Ideas.

## Current decision

- Use the Clarity Sprint as the **provisional primary offer**.
- Lead with improving IT/product capability, not AI adoption by itself.
- Keep one shared core message while language and buyer evidence are collected.
- Instrument the funnel before making strategic copy or market-split decisions.
- Do not split Mexico and US messaging from language alone.
- Treat Calendly bookings as the initial conversion and qualified conversations as the quality metric.
- Treat paid Clarity Sprints as the later revenue metric.

## Status labels

- **Confirmed:** supported by current code or repeated evidence.
- **Hypothesis:** useful belief that still needs validation.
- **Open question:** requires an answer before making a larger decision.
- **Deferred:** intentionally not decided until the stated gate is met.
